# Math4PHIL

Math4PHIL 从数学视角探索哲学问题，关注数学表示能够澄清哪些结构、保留哪些思想，以及这些对应怎样接受原文与论证的检验。项目欢迎不同哲学立场和数学方法参与讨论，并在这里分享阶段研究成果。

## 阶段报告

**目的、条件与泛性质：亚里士多德幸福论的一个局部重构**  
v0.1.9 · 2026-10-28

以《尼各马可伦理学》第一卷为例，区分共同目的的位置、幸福的活动内容与实现条件，考察省略信息、混合关系及取商对数学表示的影响。
